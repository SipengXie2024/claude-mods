## 验证边界

- 已验证正常退出后恢复；未执行进程在安装交接消息瞬间被强制终止的端到端检查。
- 未通过交互界面执行整段对话回退；笔记取自当前对话记录，活动链切换由增量同步检查覆盖。
- 模型是否在每次任务变化时都更新笔记，取决于模型对系统提示的遵循；本次只观察了一次未提示会话。
- fork 子代理只做了查询，没有在 fork 内压缩；父会话在 fork 之后写的笔记它看不到，它压缩时携带的是自己上下文里最新的笔记。
- 协议版本不一致的拒绝由存储检查覆盖；没有在一个真正停留在旧 hooks 的会话里触发。
- 过期清理由存储检查覆盖；真实归档的第一次清理发生在下一次带项目目录的查询时。项目范围的首次建索引只在 claude-mods（约 111 MB 主转录）实测；blockchain-catchup 的主转录约 721 MB，按相同速度首次约需 8 秒，未实测。
- accumulator 的完整原生压缩没有在分叉会话上重跑；插件在该规模下的归档和索引耗时来自上面的副本实测。
- 游标只核对它之前 4096 个字节；更早位置的改写不会触发重建。Claude Code 正常只追加转录；用修复工具改写过的会话，需要删除该会话的 `transcript_cursor` 行，让下一次查询从头建立索引。
