The mod never sends a second card for the turn.

The mod arms only on a prompt from the Telegram channel.

A timer edits the card at most one time in 10 seconds.

A tool event sets dirty. This keeps far below the Telegram rate limit.

Does the card reply to the message that started the task?

Each tool call changes the current line and the count.

How does the card show tools that run inside a subagent?

The card shows no raw command and no secret.

The description is text that Claude writes for a person. All text goes through redact(), also the file names.

redact() replaces known key shapes with ***.

Risk Patterns cannot find every secret. The main guard is claim 2: the card never contains the command.

At the end of the turn, the card becomes one line.

turn.complete gives the end reason and the duration.

Short tasks and terminal tasks send nothing.

Where does the mod load?
The claude-telegram session runs in /home/ubuntu. A project setting there also loads in every other session started in /home/ubuntu.

The live check runs in the claude-telegram session.

A Telegram error never stops or slows the turn.

A "_" or "*" in a description breaks Markdown parse_mode. Telegram gives 400 when the text did not change.

The token comes from the state folder of the channel.

The value is /home/ubuntu/.claude/channels/telegram-live.

Shared: one record for each Telegram turn, in memory only.

Not changing: the official telegram plugin, approvals, and other sessions.
