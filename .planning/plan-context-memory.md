# context-memory 实施计划

用户已授权将讨论中的机制写成插件。源代码位于 `mods/context-memory/`，保留仓库中其他正在进行的修改。

## 工作项

1. 实现本地 SQLite 归档辅助程序：压缩输入快照、原始转录索引、分支范围、带引用的分页查询、交接记录持久化。先用真实转录输入建立失败检查。
2. 实现 TypeScript hooks：启动时注册历史工具；持续观察与对账；记录有来源的任务交接；压缩前保存冻结输入，原样保留原生压缩结果并增加全新纯文本交接包；写入失败阻止压缩。
3. 实现并执行纯函数和真实 SQLite 检查，不使用 mock；验证身份、引用、分页、重启读取、权限与分支隔离。
4. 注册本地 marketplace，补充插件使用说明；通过验证及类型检查。
5. 运行真实 Claude Code 会话，检查压缩交接、原文查询、连续压缩、resume 与 agent 归属；发现失败时修复并重新验证受影响行为。

## 验收要求

- 压缩后的首次请求包含新的交接消息，历史查询读回真实原文。
- 引擎返回的原始消息内容和句柄不变，不重放旧工具块。
- 历史引用只允许当前会话/agent/分支的可见范围，恢复依据活动消息中的交接引用。
- 数据库存储与分页输出有明确边界，缺失或截断显式报告。
- 数据库或交接准备失败时停止压缩，不能静默继续。
- 交接记录分别标注原始事实和模型总结；后续用户要求继续更新任务。
- 检查结果与未验证限制据实交付。
